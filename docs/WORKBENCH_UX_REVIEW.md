## 自我审查与优化

- 检查了前端设置、请求白名单与处理器之间的一致性，补齐 stretch、target_kb、keep_resolution、audio_track 和 favicon fit；没有仅添加外观控件。
- 实际 PDF 检查图与最终导出由同一处理器生成，并通过像素相同测试验证；轻量 GIF 明确标注预览参数与最终参数区别。
- 浏览器回归发现旧 `/convert` 的本地路由未检查运行时 WebP 编码能力，已修复并验证不支持时经服务器实际导出。
- 服务端结果默认直接流式预览/下载，继续处理和打包只在用户触发时读取，限制 64 MiB；PDF 分页、媒体按需预览，波形只保留最多 4,096 个峰值。
- 草稿只存内存，清理对象 URL 和临时任务，控制缓存条数/体积；文本快照保留指纹而非复制完整编辑内容。历史与预设不保存原文件、输入文本或密码。
- 上传的安全边界、ZIP CRC/路径/解压体积检查、SVG 禁止嵌入、视频/Office 子进程超时和并发限制保留。
- 取消外部进程有独立回收测试；原生 PDF/图片处理可能先完成当前步骤，再响应取消。离开页面只停止等待，记录可恢复；显式取消会向服务器发出取消信号。

## 实际边界

裁剪编辑器限制为 21 百万像素、25 MB；更大的图片可先用尺寸工具在服务器缩小。

OCR 依赖本机 Tesseract 和相应语言模型，最多 20 页，不重建原文档复杂排版。Office 渲染受字体/LibreOffice 影响。静态工具拒绝动画转换；浏览器无法原生播放的媒体编码可代理试听或下载。SVG 系统库、FFmpeg 的可选编码器需部署时安装。服务器任务仍为单进程队列，文件自动过期；设备刷新后需要重新选择本地文件。这些边界在界面/说明/能力状态中明确表达。

### 最后一轮回归修复

- 开发模式重复挂载时，跨工具文件和文本承接仍然保留；新增共享状态回归测试，并在开发模式重跑浏览器流程。
- 批量取消只取消待处理任务；服务器在锁内保留刚刚完成的结果，避免取消与完成同时发生时删除可下载文件。
