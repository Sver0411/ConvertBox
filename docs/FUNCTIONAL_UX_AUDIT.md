# 功能交互与预览能力审查

日期：2026-10-02。范围：当前工具注册表中的 46 个工具、两套前端执行界面、图片/PDF/音视频处理器、数据和 ZIP 本地处理。补充 UX_AUDIT.md，聚焦功能是否便于实际使用。

本轮结论来自组件和执行路径核查，并结合上一轮浏览器走查；未逐个上传文件做 46 个工具的端到端验证。下述新增能力均是优化建议，尚未实现。P1 优先解决用户难以判断选区或输出、以及能力与入口不符的问题；P2 完善高频操作；P3 按实际需求追加。

本审查记录的是优化前的发现。2026-10-03 的实现与验收见 [工作区优化验收](WORKBENCH_UX_REVIEW.md)。

## 已有基础与覆盖范围

- 图片裁剪已有可拖动裁剪框、自由比例/固定比例、缩放和旋转。
- 整理/提取/删除 PDF 页面已有缩略图和选择；整理还支持排序和旋转。
- 批量重命名已有旧名 → 新名对照，不能将它视为完全没有预览。
- 新工具的单个本地图片结果有预览；Preview 组件也支持音视频 Blob，但服务端结果分支没有接入播放器，大多数音视频工具因此仍只有下载按钮。
- ZIP 检查已有目录列表和下载所选；数据工具已有文本输出；旧转换工作台主要显示文件行、状态和下载。

## 一、通用预览和结果区

| 编号 | 优先级 | 当前缺口 | 建议 |
| --- | --- | --- | --- |
| G1 | P1 | 不同结果路径体验不一致：旧工作台文件行、本地单图预览、服务端下载按钮、批量文件链接。 | 统一右侧结果区，按图片/PDF/音视频/文本/压缩包显示适合的预览，保留下载入口；预览也可以使用抽屉展开。 |
| G2 | P1 | 很多工具只有文件名，选择后不知道图片尺寸、媒体时长、页数或轨道。 | 选择后显示与任务相关的文件信息；原始文件预览尽量本地完成，不为看预览重复上传。 |
| G3 | P2 | 批量结果只能按名字下载，难以快速发现某张图片或某个页面处理错误。 | 文件列表加缩略图/状态/大小，点击查看单项；提供选择下载与成功项打包。 |
| G4 | P2 | 跨工具不能承接结果，裁剪→缩放→压缩→清除元数据需要反复下载、选择。 | “继续处理”列出兼容工具，明确下一步使用原文件还是当前结果，并保留返回上一份结果的入口。 |
| G5 | P1 | 新图片批处理遇到单项异常会抛出，之前成功的结果没有返回页面。 | 每项独立状态，保留已成功结果，只重试失败项；不要让一张坏图使整批成果不可访问。 |

## 二、图片工具（9 个）

覆盖：格式转换、调整尺寸、压缩、裁剪、旋转、翻转、元数据、移除元数据、网站图标。

| 编号 | 优先级 | 当前缺口 | 建议 |
| --- | --- | --- | --- |
| I1 | P1 | 压缩主要设置格式和质量，没有原图/结果的等倍率比较，也没有目标体积。 | 原图与结果左右对照或滑动比较，支持缩放；显示尺寸和体积。随后提供“尽量小于指定 KB”，无法达标时明确提示，不保证任意目标都能满足。 |
| I2 | P1 | 尺寸调整只有宽高输入、比例说明，缺少可见原尺寸和最终尺寸确认。 | 显示原宽高、比例锁、按百分比缩放、预计输出尺寸；默认保留格式，防止无意放大。 |
| I3 | P2 | 裁剪有编辑器，但没有输出像素尺寸输入、清晰的裁剪坐标、重置/撤销。 | 保留已有框选，增加实际裁剪宽高、精确输入、原图复位和撤销；换图后重置旧编辑状态。 |
| I4 | P1 | 旋转与翻转必须处理后才看到效果，不能轻松比较方向。 | 操作时即时显示变换，提供撤销和恢复原图；导出时再编码。 |
| I5 | P2 | PNG 等无损输出仍出现质量数值；透明图导出 JPG 会使用白底，但没有背景选择或效果确认。 | 按格式显示有效参数；透明底用棋盘格预览，JPG 提供背景色并预览最终合成。 |
| I6 | P2 | 移除元数据的结果只有图片，用户无法确认哪些信息清除了；ICC 是否保留需要理解技术词。 | 前后对照拍摄信息、位置、色彩配置，显示移除结果；用短中文说明保留色彩配置的作用。 |
| I7 | P2 | 元数据报告中 EXIF/GPS 的嵌套内容是原始字符串/JSON，不便阅读。 | 分组展示尺寸、色彩、拍摄、位置；明确字段为空和确实没有元数据的区别。 |
| I8 | P2 | 网站图标固定输出多尺寸 ICO，用户看不到小尺寸是否清晰或被补边。 | 展示 16/32/48 等尺寸效果和浏览器标签模拟；提供居中留白/裁剪选择，再考虑 PNG 图标包。 |
| I9 | P2 | 图像工具多接受 image/*，静态重编码可能改变动画语义，界面没有通用的动画帧说明。 | 检测动画后明确处理首帧还是保留动画，动态格式显示播放预览；不支持保留动画时提前提示。 |

## 三、PDF 与文档（14 个）

覆盖：PDF 转换、合并、拆分、旋转、优化、整理、提取页面、删除页面、水印、页码、提取内嵌图片、元数据、密码保护，以及文档转换。

| 编号 | 优先级 | 当前缺口 | 建议 |
| --- | --- | --- | --- |
| P1 | P1 | PDF 水印与页码只有数值设置，导出前看不到位置、旋转后的边界和遮挡。 | 单页预览联动设置，支持换页；水印拖动定位，字号/透明度/旋转实时反馈，确认后应用所选页。 |
| P2 | P1 | PDF 旋转、拆分、合并等旧工具没有共用缩略图编辑能力。 | 复用现有页面编辑器；合并显示文件分组及最终顺序，拆分标出分组边界和预计文件数，旋转显示结果方向。 |
| P3 | P1 | PDF 提取/删除的缩略图与手动页码不同步，整理删除没有撤销。 | 单一选择状态，“将提取/将删除 N 页”摘要；可撤销操作并保留至少一页。 |
| P4 | P2 | PDF 转图片只能看下载文件，DPI 对清晰度/尺寸的影响不可见。 | 预览选定页面、估算像素尺寸、导出页数；结果用页面缩略图浏览，不一次加载全部高清页。 |
| P5 | P1 | PDF 转 Word 是文字提取重建，扫描件无可选文字时失败，没有 OCR；用户容易期待原版排版。 | 提前检测可选文字，区分文字提取与扫描件识别，给出简短能力说明；OCR 为后续独立可选能力，识别结果可校对，不承诺还原复杂版式。 |
| P6 | P1 | “文档转 PDF”入口声明 Word/表格/演示文稿，但当前 word 视图只接受 doc/docx/odt/pdf，输出路由也只按这一组筛选。 | 修正入口与接受范围的一致性；为确实支持的表格和演示文稿提供可达入口，预览转换后的 PDF。 |
| P7 | P2 | Word/表格/演示文稿转换后没有结果检查，用户要下载后另开程序确认字体、分页、表格是否截断。 | 将生成的 PDF 接入分页预览。复杂格式显示简短转换限制；有选择地增加纸张/方向等真正由后端支持的参数。 |
| P8 | P2 | PDF 内嵌图片提取直接返回 ZIP，没有缩略图、尺寸和页码对应关系。 | 返回图片清单，预览与选择下载；显示来源页码和重复引用关系，避免把内嵌图片提取误认为整页截图。 |
| P9 | P2 | PDF 优化无法检查清晰度变化；某些文件输出可能更大。 | 显示前后体积，提供页面对照；输出未减小时明确说明，保留原文件，不用“成功”暗示已压缩。 |
| P10 | P2 | 密码保护没有已有加密 PDF 的解锁处理入口；元数据移除也缺少前后核对。 | 对合法持有密码的用户提供受控解锁流程，并明确密码不进入记录/预设；保护后显示加密结果与权限；元数据前后列表对照。 |

## 四、音频（4 个）

覆盖：转换、裁剪、合并、统一音量。

| 编号 | 优先级 | 当前缺口 | 建议 |
| --- | --- | --- | --- |
| A1 | P1 | 裁剪只有开始/结束时间，没有试听、波形或可拖动选区。 | **波形图 + 播放头 + 起止双手柄 + 精确时间输入**；点击波形定位，缩放时间轴，循环试听所选片段，显示所选时长和裁剪后试听。时间输入必须与选区同步；不能仅画一张静态波形图。 |
| A2 | P1 | 服务端音频结果只有下载，无法试听转换或裁剪是否正确。 | 所有音频工具提供原音频/结果播放器及时间、采样率、声道、体积；浏览器无法播放的输入提供明确的代理试听回退。 |
| A3 | P2 | 合并仅有文件列表和前后移动，看不到拼接点或总时长。 | 多片段时间轴、每段试听、拖动排序、接缝定位和总时长；有明确需求再加淡入淡出/交叉淡化，默认保持直接拼接。 |
| A4 | P2 | “统一音量”提供用途预设，但处理前后响度、峰值与听感没有反馈。 | 原音与结果 A/B 试听，显示测得的响度/真峰值以及目标。预设选择只代表目标，不可作为“已测得达标”的证明。 |
| A5 | P2 | 音频转换参数相同地应用于不同格式，用户不清楚有损/无损和文件大小变化。 | 按目标格式显示有效的码率、采样率、声道；显示源格式和有损转换说明，结果试听并对照体积。 |

## 五、视频（6 个）

覆盖：转换、压缩、裁剪、GIF、提取帧、提取音频。

| 编号 | 优先级 | 当前缺口 | 建议 |
| --- | --- | --- | --- |
| V1 | P1 | 视频裁剪没有播放器、缩略图时间轴和选区播放，起止时间只能手输。 | 视频播放器、缩略图轨道、双手柄选区、精确时间输入和逐帧微调；试听所选片段，导出前说明重新编码行为。 |
| V2 | P1 | 视频转 GIF 的起点、时长、帧率、宽度无法可视化确认。 | 在视频上选择片段；提供按需生成的低分辨率 GIF 预览，显示实际/估算大小并明确标注估算；调整后显式刷新预览，避免每次拖动都发全量任务。 |
| V3 | P2 | 提取帧没有指定时间的画面预览，各模式字段同时出现，结果为 ZIP。 | 播放头选帧；模式只显示相关字段；均匀/间隔模式先显示帧数与采样位置，结果联系表预览和选择下载。 |
| V4 | P1 | “压缩程度”不解释会降低分辨率；当前轻度/均衡/强力分别将高度最多限制为 1080/720/480。 | 在设置旁显示实际目标尺寸、编码方式和质量取舍；支持“保留分辨率”选项，提供代表片段前后对照。 |
| V5 | P2 | 视频转换和提取音频缺少轨道选择及结果播放；多音轨视频默认选择可能不符合用户预期。 | 显示音视频轨道、语言/声道信息，允许选择可处理音轨；提取前试听，结果音频播放器；视频结果可播放时预览。 |
| V6 | P2 | 长视频处理缺少明确的上传、排队、编码阶段和可恢复结果。 | 分阶段状态、取消、失败原因、任务恢复；没有可靠数据时不显示虚构剩余时间。 |

## 六、数据、压缩包和文件工具（13 个）

覆盖：7 个 JSON/CSV/YAML 工具、3 个 ZIP 工具、文件检查、校验值、批量重命名。

| 编号 | 优先级 | 当前缺口 | 建议 |
| --- | --- | --- | --- |
| D1 | P2 | JSON/YAML 是普通文本框和输出 pre，错误有行列信息但不能定位；JSON 校验结果过于单薄。 | 行号、错误定位、折叠与查找；保留手动处理以控制大文本开销；格式化前后并排展示，复制后有反馈。 |
| D2 | P2 | CSV 只有逗号分隔且假定第一行为表头；CSV/JSON 转换没有表格预览、列选择和嵌套映射。 | 先预览前几十行，配置分隔符/表头和列顺序，明确文本编码；嵌套对象用明确的展开规则，不能静默丢数据。 |
| Z1 | P2 | ZIP 检查与解压分为两个工具，检查页面又有自动目录和手动报告两套入口。 | 合并成“浏览与提取”体验，树形目录、搜索、全选/取消、选择提取和可安全预览的单项。 |
| Z2 | P1 | 解压结果再“下载全部 ZIP”会调用 createZip；createZip 把路径只保留末段，因此目录层级被扁平化。 | 为重新打包保留经校验的相对路径，区分保留目录与平铺导出；下载前显示实际归档路径，避免同名文件改名后失去来源关系。 |
| Z3 | P2 | 创建 ZIP 固定 level:0，仅打包；没有压缩程度、目录保留和最终清单确认。 | 明确“打包”与“压缩”，提供适当压缩级别；大文件有进度、取消及输入/输出容量提示，不需要默认最高压缩。 |
| F1 | P2 | 文件检查输出包含技术字段，媒体轨道等是嵌套 JSON，用户难以转到相应操作。 | 按类型显示可读摘要、扩展名与真实格式是否一致，提供兼容工具的下一步入口。 |
| F2 | P2 | 文件校验只能单文件输入预期字符串，缺少两个文件直接比较和校验清单。 | 提供双文件比较、预期值粘贴清理、明确一致/不一致；有批量需求再增加清单导出。 |
| F3 | P2 | 重命名有预览但错误被静默隐藏，序号固定位宽 3、日期用 UTC 当天且无日期输入、重名自动修正没有突出。 | 保留前后预览，显示冲突与替换规则；序号位数和日期可设，非法规则就地解释；明确会下载新 ZIP，不会改动设备上的原文件。 |

## 实施建议

1. **先共用预览基础**：文件信息、单项原始预览、统一结果面板、服务端预览接口和批量结果浏览。
2. **再做真正的交互编辑**：音频波形裁剪、视频时间轴、PDF 水印/页码联动预览、图片比较与精确尺寸。
3. **最后增强细节**：音量检测、轨道选择、CSV 表格配置、ZIP 目录保留、跨工具承接；OCR 等额外引擎按需求单独评估。

性能原则：图片使用缩略图、PDF 按页加载、音频波形使用分层峰值摘要、长媒体按需生成代理；限制并发和解码资源。不能为了增加预览一次加载全部高清页面或把整段长音频完全解码到内存。浏览器不支持的格式应有明确回退，预览结果和最终导出使用同一参数快照。

桌面布局建议：左侧固定分类/同类工具；右侧上方文件信息，中间为主要预览或编辑器，侧边为当前任务必要参数，下方紧凑结果区。大尺寸结果用抽屉放大查看，无需为每个工具新增独立“预览页”而增加往返步骤。
